# AI Chatbot using Python and Gemini API

## Project Description
This project is a simple interactive AI chatbot built with Python and Google's Gemini API using the OpenAI-compatible Python SDK.

## Features
- Interactive command-line chatbot
- System message to control assistant behavior
- Adjustable temperature and response length
- Error handling for API requests

## Technologies Used
- Python
- OpenAI Python SDK
- Google Gemini API

## Requirements
- Python 3
- A Gemini API key
- Internet connection

## Installation

1. Clone this repository.
2. Create and activate a virtual environment.
3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Set the `GEMINI_API_KEY` environment variable.

## Run the Project

```bash
python main.py
```
